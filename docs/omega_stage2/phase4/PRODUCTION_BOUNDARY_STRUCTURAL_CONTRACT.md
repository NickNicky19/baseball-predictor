# Production Boundary Structural Contract

Schema version: `omega-production-boundary-structural-contract-v1`.

The candidate boundary combines exact canonical-base file hashes, the retained live-plan Git blob identity, candidate-state flags, protected-path diff checks, a transitive dashboard capability allowlist, semantic IAM parsing, semantic CloudFormation parsing, and immutable GitHub Action references.

No candidate dashboard module can reach prediction runners, fitting, calibration, simulations, collectors, ledgers, scheduler control, production paths, evidence stores, AWS clients, subprocesses, or filesystem writes. The tests also mutate aliases, wrappers, environment lookups, IAM, workflows, and network resources so the gate is not limited to current names.

This is structural evidence only. It is not a claim about a deployed AWS boundary, publisher, model, or evidence pipeline.
